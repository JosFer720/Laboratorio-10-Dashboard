# Figuras de evidencia

Estos PNG son exportaciones de las figuras JSON que devolvió el servidor real de la versión `lab10-final` durante las tres pruebas HTTP. Se agregaron títulos de contexto para su lectura en el informe, sin modificar los datos. No son capturas de pantalla del navegador ni de Power BI Desktop.

- `dash_prueba1_exportacion.png`: llegadas mensuales de 2025, todos los mercados.
- `dash_prueba2_exportacion.png`: mercados de América Central en 2025.
- `dash_prueba3_series_exportacion.png`: observado y estimado de LSTM.
- `dash_prueba3_error_exportacion.png`: error mensual de LSTM.

Las capturas de las interfaces y la medición de clics permanecen sin obtener por las limitaciones registradas en `../entorno_pruebas.json`.
